**Battlescape Map**
The battlescape map has three dimensions: width, height, and number of levels. Each location in the map is represented by the MapLocation class which has the three properties: Level (0 to Levels - 1), Row (0 to Height - 1), and Column (0 to Width - 1). A MapLocation can be represented as "(Level, Row, Column)" (e.g. (0, 1, 2) for Level = 0, Row = 1, Column = 2). The map is drawn as an isometric view. Each location has a graphical representation that is 32 pixels wide and 40 pixels tall, though the corners of that area are not used and always transparent. There are 8 supported directions on the map, represented by the Direction enum. These directions line up with how directions on a map normally would be interpreted if you were looking down at the map. However, the isometric view will have North going up and to the right, NorthEast to the right, etc. The map is drawn as a series of sprites. The order the sprites are drawn is important so that the final representation looks correct (sprites drawn later will obstruct sprites drawn earlier, for example).

**Levels**
The "bottom" level (represented by Level = 0) is drawn first, followed by the next level, etc. The battlescape view supports an active level represented by the Map.SelectedLevelIndex. Mouse interactions with the map are only performed on this selected level. There is also a full-map mode (not yet implemented, see Battlescape.OnToggleLevelView TODO). This full-map mode is off by default but can be toggled by clicking the battlescape menu button. When it is off, only levels up to the selected level are rendered. When it is on, all levels are rendered. For a given level, map locations are then draw left-to-right (Column 0 to Width - 1) and then top-to-bottom (Row 0 to Height - 1).

**Translation to Graphics Buffer coordinates**
The map will be rendered at a given top/left coordinate represented by the Map.RowOffset and Map.ColumnOffset properties. The map location (0, 0, 0) (first column of the first row of the bottom level) will be rendered at this location. Then map location (0, 0, 1) (second column) will be rendered next, adjusting the X-offset by 16 pixels and the Y-offset by 8 pixels. When (0, 1, 0) (first column of the second row) is drawn, it will be adjusted with an X-offset of -16 and Y-offset of 8 relative to the (0, 0, 0) map location. When (1, 0, 0) (first column of the first row of the second level) is drawn, it will be adjusted with an X-offset of -24.

**Anatomy of a Map Location**
A single map location can be thought of as a cubic unit of the map. It will be drawn as an isometric cube. The cube will be drawn at an X,Y coordinate for the graphics buffer. This represents the top/left corner of the map location image. The image will be a 32-pixel wide by 40-pixel tall sprite. The logical "top" of the cubic unit would be represented by a 32-pixel wide by 16-pixel tall isometric rectangle with the logical "NorthWest" corner at the top/center of the image, the "NorthEast" corner at the right edge of the image, 8-pixels down, the "SouthEast" corner at the center of the image, 16-pixels down, and the "SouthWest" corner at the left edge of the image, 8-pixels down. The "North" wall, "West" wall, and "Ground" surfaces are represented by the Tile class parts. Tiles do not have South wall, East wall, or Ceiling surfaces. A tile may also have either an "entity" (something that does not move, like a lamp post) or a unit occupying that location (like a soldier, civilian, or alien). When drawing a map location, the order of sprites drawn should be: Ground, North Wall, West Wall, and then the Entity/Unit occupying that location. Note that a unit may not occupy a location that has an entity (it obstructs them) so a location never has both.

**Active Solider Indicator**
The active solider indicator should be drawn as if it were in the map location in the level above the soldier. If the level above the soldier is being rendered, the indicator would be drawn after the Ground part but before the entity/soldier occupying it. If the level above the soldier is not being rendered, the indicator should still be rendered but without any other attributes of the map location from above. If the soldier is in the top-most level, the cursor should still be drawn as-if it were in an empty level above the top-most level.
